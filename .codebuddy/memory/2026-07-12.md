### 关键发现
- **最严重缺陷**: VIP 权限表允许 pro/enterprise 用户使用 http/code/condition/loop 节点，但 DSL 转换器仅支持 start/llm/end，导致权限校验通过但执行必失败
- **前端硬编码**: API Key `demo-api-key-001` 写死在 `gateway-run/index.tsx`，所有用户共享 demo 账号
- **无登录体系**: 无注册/登录接口，无密码字段，无 JWT/Session
- **CORS 风险**: `origin: true` + `credentials: true` 违反安全规范
